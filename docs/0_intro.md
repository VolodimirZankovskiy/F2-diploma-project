# ВСТУП

## Актуальність теми
Існуючі інформаційні системи у сфері рекреаційної та спортивної риболовлі обмежуються базовою агрегацією статистичних даних без застосування методів інтелектуального аналізу. Інженерна проблема полягає у відсутності консолідованих механізмів обробки мультимодальних датасетів (гідрометеорологічні умови, геолокація, параметри спорядження) та високій обчислювальній складності виявлення неочевидних кореляцій у реальному часі. Розробка спеціалізованої платформи на базі гібридної архітектури баз даних та алгоритмів машинного навчання дозволить вирішити проблему масштабованого накопичення телеметрії та забезпечить детерміноване прогнозування ефективності.

## Об'єкт дослідження
Процес інтелектуального аналізу та прогнозування ефективності риболовлі на основі агрегації мультимодальних гідрометеорологічних та телеметричних даних.

## Предмет дослідження
Моделі машинного навчання (зокрема алгоритми класифікації), архітектурні патерни проєктування REST-систем та технології гібридного збереження даних (Polyglot Persistence).

## Мета роботи
Проєктування та розробка інтелектуальної аналітичної платформи для оптимізації процесу прогнозування ефективності риболовлі шляхом впровадження моделей машинного навчання та гібридного збереження даних, що дозволить підвищити детермінованість та точність оцінки успішності майбутніх сесій.

## Завдання проєкту
1. Проаналізувати предметну область, існуючі інформаційні системи та методи прогнозування на основі телеметричних даних.
2. Обґрунтувати вибір технологічного стеку та методів машинного навчання для вирішення задачі класифікації.
3. Спроєктувати архітектуру програмного рішення (з використанням нотації C4) та схеми гібридної системи баз даних.
4. Розробити та натренувати алгоритмічне ядро (ML-модель) для предиктивного аналізу.
5. Спроєктувати та реалізувати REST API платформи з імплементацією механізмів асинхронного збору даних.
6. Провести інструментальний аудит, профілювання та тестування розроблених програмних модулів.
7. Налаштувати CI/CD конвеєр, розгорнути платформу у хмарному середовищі та провести практичну апробацію результатів.
