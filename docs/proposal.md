# Thesis Proposal: Intelligent Analytical Platform for Fishing Efficiency

**Попередня робоча назва проєкту:** 
Укр: Проєктування та розробка інтелектуальної аналітичної платформи для прогнозування ефективності риболовлі.
Eng: Design and development of an intelligent analytical platform for predicting fishing efficiency.

**Актуальність та проблематика:** 
Існуючі інформаційні системи у сфері спортивної та рекреаційної риболовлі обмежуються базовою агрегацією статистичних даних без застосування методів інтелектуального аналізу (Data Mining). Відсутність алгоритмів машинного навчання для виявлення неочевидних кореляцій між гідрометеорологічними факторами, геолокацією та характеристиками спорядження унеможливлює побудову детермінованих предиктивних моделей ефективності.

**Сформована ідея продукту:** 
Проєктування Cloud-Native платформи збору телеметрії та предиктивної аналітики, що відповідає парадигмі AI & Data Engineering. Архітектурне рішення базується на гібридній моделі збереження даних (Polyglot Persistence) для накопичення мультимодальних датасетів та інтеграції навченої ML-моделі для генерації ймовірнісних прогнозів у реальному часі.

**Детальний опис функціоналу (Core Features):**
1. Агрегація та парсинг гідрометеорологічних метрик (тиск, фази місяця, вітер) через асинхронну інтеграцію з зовнішніми REST API метеорологічних провайдерів.
2. Розробка, тренування та розгортання ML-моделі класифікації (наприклад, Random Forest) для предиктивного розрахунку скорингового балу успішності сесії.
3. Реалізація гібридної системи збереження даних: нормалізована реляційна модель для керування профілями/арсеналом та документо-орієнтована СУБД для акумуляції неструктурованих логів.
4. Побудова аналітичних вітрин для багатокритеріальної візуалізації статистики користувача.
5. Налаштування наскрізного CI/CD конвеєра для автоматизованого лінтингу, тестування та деплою бекенд-сервісів.
6. Впровадження контуру спостережуваності (Observability) для проактивного моніторингу метрик продуктивності API (Latency, Error Rate).

**Інструментарій та технологічний стек:**
*   **Мови програмування:** Python.
*   **AI & Data Engineering:** scikit-learn, pandas, NumPy.
*   **Архітектурні патерни та фреймворки:** REST, Clean Architecture, FastAPI, Pydantic.
*   **Бази даних:** PostgreSQL, MongoDB (з використанням асинхронних ODM/ORM Motor).
*   **DevOps та інфраструктура:** Docker, GitHub Actions (CI/CD), Prometheus + Grafana (Observability).
